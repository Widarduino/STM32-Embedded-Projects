### Description
This repo contains code for embedded C programming on stm32f103 "bluepill" dev board
All code is heavily inspired from code taken from the book **Bare-Metal Embedded C Programming by Israel Gbati.**
and is simply adjusted to fit the peripherals of the stm32f104 chip

feel free to use this repo as a reference however please do keep in mind that code may be written in ways that are not necessarily optimial and should be used for the sake of learning.

Additional Notes: I will make an effort to include images and detailed descriptions at some point in time
